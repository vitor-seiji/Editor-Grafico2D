# Editor Gráfico 2D

Um aplicativo de editor gráfico 2D interativo desenvolvido para a criação, manipulação e renderização de formas e elementos visuais de maneira simples e intuitiva.

---

## Funcionalidades

- **Desenho de Primitivas Geométricas:** Crie linhas, retângulos, círculos, polígonos ou formas livres.
- **Ferramentas de Manipulação:** Mova (translação), redimensione (escala) e rotacione os objetos na tela.
- **Gerenciamento de Cores e Estilos:** Selecione cores para bordas e preenchimentos, ajuste a espessura de linhas, etc.
- **Camadas / Objetos:** Organização de elementos gráficos em cena.
- **Exportação/Importação:** Salve seus projetos ou exporte as criações gráficas.
